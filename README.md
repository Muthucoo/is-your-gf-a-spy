# Is Your GF a Spy? 🕵️‍♀️
A playful, animated, mobile-friendly recreation of the supplied hand-drawn flowchart.

## What's inside
- `index.html` — page structure and recreated evidence board
- `style.css` — paper texture, hand-drawn-inspired styling, responsive layout and animations
- `script.js` — interactive Yes/No investigation and comedic outcomes
- `assets/original-flowchart.jpg` — the original reference image

## Run locally
Open `index.html` in a browser. No build tools or dependencies required.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `is-your-gf-a-spy`).
2. Upload all files and folders in this project to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish your site.

Your site will be available at `https://YOUR-USERNAME.github.io/is-your-gf-a-spy/`.

## Notes
This is satire, not a real assessment tool. The original chart's Taiwan/classified-documents branch is visually ambiguous, so the interactive version labels that endpoint **VERY SUSPICIOUS** rather than inventing a more specific conclusion.
